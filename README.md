# Bienvenido a myToDo 👋

Esta app es para gestionar mis proyectos y tareas.

No te ha pasado que estas lejos de tu pc de desarrollo y te llega una idea o alguna funcion nueva que quieres agregarle a tu app o proyecto y no quieres que se te olvide?

Justo para eso es esta app mobile.

- Aqui podras agregar tareas y proyectos.
- Podras ver y guardar los errores con los que te encontraste para luego resolverlos mas facil si lo vuelves a encontrar.
- Podras cambiar el estado de las tareas: pendientes, en progreso y completadas.


## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```
